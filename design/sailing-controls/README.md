# Sailing control studies

Compare [three proposals](http://localhost:5173/design/sailing-controls/index.html) for replacing the controls below the game with controls inside the 4:3 playfield. Full command strip exposes the main destinations, Compact strip keeps Menu/Chart/Pause/Speed visible, and HUD controls place pause and speed beside the sailing readouts. Each proposal can toggle pause, cycle 1X/4X/16X, and open a sample command menu. The scene picker shows the relationship to the harbor hub.

This page uses the existing scenery and ship art but never reads or writes a saved voyage. It does not change the game's controls. Space for pause, T for speed, and the current menu shortcuts can remain in all three proposals. Keyboard reference belongs in the handbook rather than an exterior help bar.
